5 分鐘快速開始

只需幾個簡單步驟即可在您的伺服器上執行 LLMChat。

1
克隆儲存庫
git clone https://github.com/anomixer/llmchat.git && cd llmchat
2
安裝依賴套件
npm install
3
設定環境變數

複製 .env.example 為 .env 並設定您的 LLM 服務商：

cp .env.example .env && nano .env
4
啟動 Ollama（若使用本地模型）
ollama serve
5
執行應用程式
npm run dev

🎉 訪問 http://localhost:5173 開始聊天！如需生產部署，請查閱完整文件。

常見問題

我可以使用雲端 LLM 服務商嗎？ ▼
Yes! LLMChat supports 20+ providers including OpenAI, Claude, Gemini, and others. You can configure API keys in the .env file and switch between providers seamlessly from the UI.
我的資料會存儲在雲端嗎？ ▼
No. With local models (Ollama), 100% of your data stays on your server. Even with cloud LLM providers, conversations are stored locally and you have full control. No external logging or analytics.
系統需求是什麼？ ▼
Minimum: Node.js 18+, NPM 8+. For local LLM models: Ollama (requires 8GB RAM recommended). For cloud-only setup: minimal requirements. Full instructions in the GitHub repository.
如何將 LLMChat 部署到生產環境？ ▼
LLMChat supports Docker containerization. Build with: npm run build, then deploy using the provided Dockerfile. Supports nginx/Apache reverse proxy, SSL/TLS certificates, and load balancing. See deployment guide in docs.
我可以自訂 UI 嗎？ ▼
Absolutely! LLMChat is built with React + TypeScript + CSS. All components are modular and well-documented. You can easily customize colors, branding, layout, and functionality to match your organization's needs.
